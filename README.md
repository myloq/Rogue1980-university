# Rogue 1980 — roguelike-игра на C#

## Описание проекта

Университетский проект по дисциплине «Программирование».  
Кроссплатформенное игровое приложение в жанре roguelike, созданное в духе классической игры Rogue 1980 года.

Игра реализует пошаговое исследование процедурно генерируемых подземелий, сражения с противниками, сбор предметов и сокровищ, а также ведение статистики прохождений. Проект выполнен с разделением на слои: домен, представление, слой данных и точку входа (App). Сохранение состояния игры и таблицы лидеров производится в формате JSON.

## Цель проекта

Разработать кроссплатформенное приложение на языке C# версии 12 с чистой многослойной архитектурой, реализующее основные механики классической игры Rogue 1980 года, и обеспечить соблюдение принципов чистой архитектуры и инверсии зависимостей.

## Технологический стек

- **Язык программирования:** C# 12
- **Платформа:** .NET 10
- **Пользовательский интерфейс:** Raylib-cs
- **Формат хранения данных:** JSON
- **Целевые операционные системы:** Windows, Linux

## Архитектура приложения

Приложение построено по многослойной архитектуре с использованием принципа инверсии зависимостей. Слои взаимодействуют только через интерфейсы.

### Слои

1. **Domain**  
   Содержит игровые сущности, логику генерации уровней, пошаговый геймплей, бой, поведение противников, предметы и инвентарь.  
   Не зависит от слоёв Presentation и DataLayer.

2. **Presentation (Представление)**  
   Отвечает за рендеринг игрового мира и интерфейса (с использованием Raylib), обработку пользовательского ввода, туман войны, стартовое меню и таблицу лидеров.  
   Взаимодействует с Domain через интерфейсы `IGameStateProvider` и `IGameCommandHandler`, с DataLayer — через `ILeaderboardProvider`.

3. **DataLayer (Доступ к данным)**  
   Обеспечивает сохранение и загрузку игровой сессии, а также хранение статистики всех прохождений и таблицы лидеров в JSON-файлах.  
   Взаимодействует с Domain через `IGameStateRepository` и `IGameStateLoader`.

4. **App (Точка входа и композиция)**  
   Является исполняемым проектом и единственным местом, где создаются конкретные реализации интерфейсов. Отвечает за сборку приложения: инициализирует слои Domain, Presentation и DataLayer, внедряет зависимости через конструкторы и запускает главный игровой цикл.

## Реализованные функциональные возможности

- **Стартовое меню:** новая игра, продолжение сохранённой сессии, таблица лидеров, выход.
- **Процедурная генерация:** 21 уровень подземелья, каждый из которых состоит из 9 комнат, соединённых коридорами.
- **Пошаговый режим:** каждое действие игрока (движение, использование предмета) запускает ход противников.
- **Управление:** перемещение персонажа с помощью клавиш WASD.
- **Бой:** проверка попадания по ловкости, расчёт урона по силе и оружию, применение урона.
- **Пять типов противников:** зомби, вампир, привидение, огр, змей-маг. Каждый тип имеет уникальный паттерн поведения (BFS-преследование, телепортация, диагональное движение и т.д.).
- **Инвентарь:** оружие, еда, эликсиры, свитки. Использование предметов через клавиши `h`, `j`, `k`, `e` с выбором кликом мыши.
- **Подбор предметов:** автоматический подбор при наступании. Максимум 9 предметов каждого типа, сокровища накапливаются в одной ячейке.
- **Туман войны:** неизведанные области скрыты, просмотренные комнаты отображаются тускло, текущая область видимости рассчитывается с помощью алгоритма Брезенхэма.
- **Переход на уровень:** при касании блока выхода в конечной комнате.
- **Условия завершения:** победа при прохождении 21 уровня, поражение при снижении здоровья до 0 или ниже.
- **Сохранение:** автоматическое сохранение состояния после каждого уровня и восстановление полной информации об игровой сессии (включая позиции сущностей).
- **Таблица лидеров:** сортировка по количеству собранных сокровищ, отображение достигнутого уровня, убитых врагов, съеденной еды, выпитых эликсиров и других метрик.

## Сборка и запуск

Предварительные требования
- Установленный .NET SDK 10.

Для работы графики используется библиотека Raylib-cs (устанавливается автоматически через NuGet).

Инструкция по сборке

Клонировать репозиторий:

```bash
git clone <URL_репозитория>
cd Rogue1980-university
```

Восстановить зависимости и собрать проект:

```bash
dotnet restore
dotnet build
dotnet run --project Rogue1980.App
```
