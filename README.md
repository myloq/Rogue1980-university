# Rogue1980-university

## Описание проекта
**Университетский групповой проект** по дисциплине «Программирование».  
Кроссплатформенное игровое приложение в жанре roguelike, созданное в духе классической игры Rogue 1980 года.

Игра реализует пошаговое исследование процедурно генерируемых подземелий, сражения с противниками, сбор предметов и сокровищ, а также ведение статистики прохождений. Проект выполнен с разделением на слои: домен, представление и слой данных. Сохранение состояния игры и таблицы лидеров производится в формате JSON.

## Цель проекта
Разработать кроссплатформенное приложение на языке C# версии 12 с чистой многослойной архитектурой, реализующее основные механики классической игры Rogue 1980 года, и обеспечить возможность командной разработки с чётким разделением ответственности между участниками.

## Технологический стек
- Язык программирования: C# 12
- Платформа: .NET 8
- Формат хранения данных: JSON
- Целевые операционные системы: Windows, Linux

## Архитектура приложения
Приложение построено по многослойной архитектуре с использованием принципа инверсии зависимостей. Слои взаимодействуют только через интерфейсы.

### Слои
1. **Domain**  
   Содержит игровые сущности, логику генерации уровней, пошаговый геймплей, бой, поведение противников, предметы и инвентарь.  
   Не зависит от слоёв Presentation и DataLayer.

2. **Presentation (представление)**  
   Отвечает за рендеринг игрового мира и интерфейса, обработку пользовательского ввода, туман войны, стартовое меню и таблицу лидеров.  
   Взаимодействует с Domain через интерфейсы `IGameStateProvider` и `IGameCommandHandler`, с DataLayer - через `ILeaderboardProvider`.

3. **DataLayer (доступ к данным)**  
   Обеспечивает сохранение и загрузку игровой сессии, а также хранение статистики всех прохождений и таблицы лидеров в JSON-файлах.  
   Взаимодействует с Domain через `IGameStateRepository` и `IGameStateLoader`.
4. **App (точка входа и композиция)**  
   Является исполняемым проектом и единственным местом, где создаются конкретные реализации интерфейсов. 
   Отвечает за сборку приложения: инициализирует слои Domain, Presentation и DataLayer, внедряет зависимости через конструкторы и запускает главный игровой цикл.

## Функциональные возможности

- Стартовое меню: новая игра, продолжение сохранённой сессии, таблица лидеров, выход.
- Процедурная генерация 21 уровня подземелья. Каждый уровень состоит из 9 комнат, соединённых коридорами, с проверкой связности графа.
- Пошаговый режим: каждое действие игрока запускает ход противников.
- Перемещение персонажа с помощью клавиш WASD.
- Бой с противниками: проверка попадания по ловкости, расчёт урона по силе и оружию, применение урона.
- Пять типов противников: зомби, вампир, привидение, огр, змей-маг. Каждый тип имеет уникальный паттерн поведения.
- Инвентарь: оружие, еда, эликсиры, свитки. Использование предметов через клавиши `h`, `j`, `k`, `e` с выбором цифрой от 1 до 9.
- Автоматический подбор предметов при наступании. Максимум 9 предметов каждого типа, сокровища накапливаются в одной ячейке.
- Туман войны: неизведанные области скрыты, просмотренные комнаты отображаются только стенами, текущая комната - полностью. Для области прямой видимости используются алгоритмы Ray Casting и Брезенхэма.
- Переход на следующий уровень при касании блока в конечной комнате.
- Победа при прохождении 21 уровня. Поражение при снижении здоровья до 0 или ниже.
- Сохранение состояния после каждого уровня и восстановление полной информации об игровой сессии.
- Таблица лидеров, отсортированная по количеству собранных сокровищ. Отображает достигнутый уровень, количество побеждённых противников, съеденной еды, выпитых эликсиров, прочитанных свитков, нанесённых и пропущенных ударов, пройденных клеток.
- Двери и цветные ключи с использованием алгоритмов поиска в глубину/ширину для проверки доступности и отсутствия софтлоков.
- Автоматическая подстройка сложности под уровень игрока.
- Противник Мимик, имитирующий предметы.
